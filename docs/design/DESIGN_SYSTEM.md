# Pixel Station design system

Active full-screen concept: `chat-concept.png` (1536 × 1024), generated with the built-in Image Gen tool from the user's visual brief. It is a design reference, not runtime application output.

Dark navy graphite background (#10111b), sidebar (#141520), subtle borders (#292b3c), primary violet (#9e8af7), readable neutral text (#eeedf8), muted labels (#9a9db4). Modern Segoe UI/Inter typography, normal body 14–16 px, labels 12 px. The fox logo and Silkscreen wordmark use a pixel treatment; six related fox portraits identify Poker seats. A restrained forest, mountain, cabin and lake scene sits beneath both side panels. See [bundled assets and prompts](ASSETS.md).

Layout is a collapsible left rail, dominant central workspace with minimal 64–72 px top bar and independently collapsible right inspector. Chats and Games retain independent expansion preferences, as do inspector sections. Main controls use restrained 8 px corners, thin borders and clear keyboard focus. Navigation and libraries use compact rows/open panels. Small violet action buttons are reserved for primary actions. SVG disclosure carets stay centered; native select options have explicit dark backgrounds and light text.

The empty Chats surface has the title “New chat”, instruction “Send a message to begin.”, a paperclip composer with “Message Pixel Station”, a send arrow, and “Enter to send”. Navigation contains Chats, Image Studio, Files, Memory, Web, Gmail, Calendar, Games and Settings. There are no prompt suggestions, marketing slogans or runtime/offline labels.

Other requested feature views extend these tokens with functional forms, source lists, confirmation dialogs, document previews and the Poker table. Responsive layouts keep the composer usable and collapse inspector/rail on narrower screens. Closed regions are inert and hidden from assistive technology; drawer dismissal restores focus. Panel widths and disclosure heights animate, while page navigation is immediate. Reduced motion disables ornamental movement. Poker separately retains a readable action pace and highlights the actual actor; animations depict saved chip payments and street reveals.
