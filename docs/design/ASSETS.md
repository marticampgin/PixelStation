# Pixel Station visual assets

Generated for the interface refinement using Codex's built-in Image Gen tool, in generation mode. These are bundled public UI assets, with no runtime or account content. They do not verify Pixel Station's separate local ComfyUI integration. Portraits use transparent backgrounds; the panel landscapes are opaque. CSS preserves the pixel treatment.

- `frontend/public/assets/fox-logo.png`: brand fox; also used for Poker seat 0.
- `frontend/public/assets/panel-forest.png`: midnight forest, lake and cabin behind the left navigation panel.
- `frontend/public/assets/panel-forest-right.png`: neighboring forest and rocky lakeshore behind the right context panel; generated with the left landscape as a style/world reference.
- `frontend/public/assets/poker/seat-1.png` through `seat-5.png`: blue scarf, golden glasses, teal hood, pink cap and amber bandana foxes.
- `frontend/public/assets/fonts/Silkscreen-Regular.ttf`: [Silkscreen](https://fonts.google.com/specimen/Silkscreen), bundled with its [SIL Open Font License](https://github.com/google/fonts/blob/main/ofl/silkscreen/OFL.txt). Used for the wordmark, with readable UI type elsewhere.

## Generation prompts

### Brand

Use case: logo-brand. Production UI asset: a single pixel-art fox face logo for Pixel Station. Transparent background. Symmetrical front-facing fox head with tall pointed ears, square stepped silhouette, pale lavender face outline and violet indigo ear shadows, two small bright square eyes and a tiny pixel nose. Match refined 1990s 16-bit dark navy desktop UI style, violet #a58aff and pale #cbb9ff. Clearly FOX, not cat: long pointed muzzle and cheek tufts, fox ears. Draw with a disciplined 32x32 or 48x48 pixel grid scaled with perfectly crisp hard square edges. Tight centered crop with the full mark occupying 85% of the square canvas. No text, no badge, no border container, no glow, no gradients, no shadows, no watermark. This will be rendered as a 36px navigation logo and as a small assistant avatar.

### Left landscape

Use case: stylized-concept. Production background asset for narrow desktop side panels. A tall portrait 2:3 pixel-art night scene in a refined 16-bit navy and violet palette, matching a dark personal AI workstation. Upper two thirds are nearly empty deep navy #10131f sky so UI content can stay readable. All scenery sits in the bottom third: layered dark indigo pine forests, a small distant violet mountain, a tiny timber cabin with two warm golden illuminated windows near the lower right, a quiet lake reflecting a few golden and violet pixels at the bottom edge. Crisp square pixels, disciplined pixel grid, restrained atmospheric detail, no painted/blurred edges. Bottom edge dense foreground pines; top fades naturally into matching dark navy sky. No text, no logos, no UI, no buttons, no stars behind the upper content. Elegant and calm. Opaque background.

### Right landscape

Generated by Codex's built-in `image_gen` tool, using `frontend/public/assets/panel-forest.png` as a style and world reference. The new view continues farther right with a lower ridgeline, denser pines and a rocky lakeshore; it has no cabin. The left landscape remains unchanged.

The selected original is `$CODEX_HOME/generated_images/01a1010b-01d6-7c71-b2d7-141abf67dfce/exec-ad53b399-e380-40ae-b424-2ddfe5b58e52.png`. It was copied unchanged to `frontend/public/assets/panel-forest-right.png`: 1024 × 1536 pixels, opaque RGB PNG, 1,617,268 bytes.

Exact final prompt:

```text
Use case: stylized-concept.
Asset type: opaque 2:3 portrait background for a narrow app side panel, whose scenery will be viewed in a 225px-tall footer.
Input image: the provided forest image is a STYLE AND WORLD reference only. Create a new neighboring view, not an edit or duplicate.
Primary request: a matching crisp 16-bit pixel-art night forest and lakeshore continuation, as if the camera turns farther to the right from the reference. Keep its deep navy and muted violet palette and pixel scale, but use clearly different silhouettes: a lower, asymmetrical distant ridgeline, denser pine clusters, and a rocky stream shore joining the lake. Use the same calm nighttime lighting and dark reflections.
Composition: the upper TWO THIRDS must be almost empty, nearly uniform deep navy #10131f, with no prominent objects. Confine the landscape to the lower third. Compose broad, readable silhouettes that remain clear in a narrow footer. Distinct rocky shoreline in the foreground, dark layered pines and a quiet stream/lake in the bottom third. The world should feel continuous with the reference while the composition is unmistakably different.
Style: sharp, deliberate square pixel clusters, classic restrained 16-bit game background, minimal shading bands, opaque full image, 2:3 portrait.
Avoid: any cabin or other building; a second cabin; copying or mirroring the original composition; the original centered mountain peak; moon, stars, bright highlights, added characters, animals, UI, text, borders, logos, watermarks, gradients that obscure the pixel art, blur, painterly texture, noise.
```
