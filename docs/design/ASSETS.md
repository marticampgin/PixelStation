# Pixel Station visual assets

Generated for the interface refinement using Codex's built-in Image Gen tool, in generation mode. These are bundled public UI assets, with no runtime or account content. They do not verify Pixel Station's separate local ComfyUI integration. Portraits use transparent backgrounds; the panel landscape is opaque. CSS preserves the pixel treatment.

- `frontend/public/assets/fox-logo.png`: brand fox; also used for Poker seat 0.
- `frontend/public/assets/panel-forest.png`: midnight forest, lake and cabin behind both side panels.
- `frontend/public/assets/poker/seat-1.png` through `seat-5.png`: blue scarf, golden glasses, teal hood, pink cap and amber bandana foxes.
- `frontend/public/assets/fonts/Silkscreen-Regular.ttf`: [Silkscreen](https://fonts.google.com/specimen/Silkscreen), bundled with its [SIL Open Font License](https://github.com/google/fonts/blob/main/ofl/silkscreen/OFL.txt). Used for the wordmark, with readable UI type elsewhere.

## Generation prompts

### Brand

Use case: logo-brand. Production UI asset: a single pixel-art fox face logo for Pixel Station. Transparent background. Symmetrical front-facing fox head with tall pointed ears, square stepped silhouette, pale lavender face outline and violet indigo ear shadows, two small bright square eyes and a tiny pixel nose. Match refined 1990s 16-bit dark navy desktop UI style, violet #a58aff and pale #cbb9ff. Clearly FOX, not cat: long pointed muzzle and cheek tufts, fox ears. Draw with a disciplined 32x32 or 48x48 pixel grid scaled with perfectly crisp hard square edges. Tight centered crop with the full mark occupying 85% of the square canvas. No text, no badge, no border container, no glow, no gradients, no shadows, no watermark. This will be rendered as a 36px navigation logo and as a small assistant avatar.

### Landscape

Use case: stylized-concept. Production background asset for narrow desktop side panels. A tall portrait 2:3 pixel-art night scene in a refined 16-bit navy and violet palette, matching a dark personal AI workstation. Upper two thirds are nearly empty deep navy #10131f sky so UI content can stay readable. All scenery sits in the bottom third: layered dark indigo pine forests, a small distant violet mountain, a tiny timber cabin with two warm golden illuminated windows near the lower right, a quiet lake reflecting a few golden and violet pixels at the bottom edge. Crisp square pixels, disciplined pixel grid, restrained atmospheric detail, no painted/blurred edges. Bottom edge dense foreground pines; top fades naturally into matching dark navy sky. No text, no logos, no UI, no buttons, no stars behind the upper content. Elegant and calm. Opaque background.
